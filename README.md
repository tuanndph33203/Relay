# Relay — The Handoffs Run Themselves

A high-performance, dark cyber-minimalist SaaS landing page built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **Lenis**.

Inspired by luxury tech aesthetics (Linear, Vercel, Awwwards), featuring dynamic fiber-optic light streams, interactive workflow canvases, 3D monolithic charts, spotlight hover effects, and an interactive pricing calculator.

## ✨ Features

- **Intro Splash Screen**: Fullscreen neon lime scaling card reveal with custom icon animation.
- **Scroll-Driven Light Stream**: High-performance HTML5 Canvas rendering 36+ luminous Bezier strands and flowing photon particles that dynamically bend with scroll depth and mouse cursor position.
- **Magnetic Custom Cursor**: Trailing glowing neon lime ring with spring physics and magnetic hover states over clickable components.
- **Spotlight Cards**: Cursor-following radial gradient glow on all glassmorphic dark cards.
- **Interactive Workflow Canvas**: Node graph editor (Stripe -> Condition -> Postgres / Ask Finance) with animated packet pulses and live latency log drawer.
- **Interactive 3D Bar Chart**: Monolithic weekday pillar chart with spring hover states and tooltips.
- **Multi-Region Data Residency**: Interactive compliance breakdown with live ping latency indicators.
- **Interactive Pricing Calculator**: Real-time slider (3,000 to 300,000 runs) that dynamically recalculates pricing tiers and updates recommended plans.
- **Butter-Smooth Momentum Scrolling**: Powered by Lenis.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/tuanndph33203/Relay.git

# Navigate to project folder
cd Relay

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to see the live app.

### Production Build

```bash
npm run build
npm run preview
```
